# CROSSROAD User Guide

## Getting Started

### Accessing the Platform

1. Open your browser to `http://localhost:3000`
2. Login with your credentials
3. Explore the dashboard

## Main Features

### 1. Graph Explorer

Interactive network visualization of political relationships.

**How to Use**:
- Search for a person in the search bar
- Click nodes to see details
- Drag nodes to rearrange
- Use mouse wheel to zoom
- Right-click for context menu

**Filters**:
- Relationship types (Family, Business, Political)
- Time periods
- Risk levels

### 2. Person Profile

Detailed dossier on political figures.

**Sections**:
- Biography
- Family tree
- Business interests
- Legal cases
- Wealth history
- Oligarchy score

### 3. Natural Language Query

Ask questions in plain Indonesian or English.

**Examples**:
- "Siapa anggota DPR yang punya perusahaan tambang?"
- "Show all companies owned by Governor of East Kalimantan"
- "Tunjukkan konflik kepentingan di Kalimantan Timur"

### 4. Dynasty Tracker

Visualize political family networks.

**Features**:
- Family tree visualization
- Multi-generational tracking
- Power concentration analysis
- Wealth inheritance patterns

### 5. Budget Flow Monitor

Track APBD money flow and detect anomalies.

**Views**:
- Sankey diagram of budget flows
- Project status dashboard
- Anomaly alerts
- Contractor networks

## Common Tasks

### Finding Corruption Risks

1. Go to "Analytics" → "Oligarchy Detection"
2. Select region or person
3. Review risk scores
4. Export report

### Tracking Legal Cases

1. Search for person name
2. Click "Legal Cases" tab
3. View case timeline
4. Set up alerts for updates

### Investigating Companies

1. Go to "Business" → "Company Search"
2. Enter company name or NPWB
3. View ownership structure
4. Check government contracts
